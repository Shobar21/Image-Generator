# AIGenerateImage – text to image

1. Install Node.js 18 or newer (LTS).
2. Get a free account + API key at https://enter.pollinations.ai
3. Copy `.env.example` to `.env` and fill MONGO_URL and POLLINATIONS_API_KEY.
4. In Atlas: Network Access -> Add IP -> Allow access from anywhere (0.0.0.0/0).
5. Run:
   npm install
   npm start
6. Open http://localhost:5000
